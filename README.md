# StudentOS

> Know Your Next Step.

StudentOS is an AI-powered career operating system that helps students discover opportunities, build skills, and confidently make career decisions.

## 🎯 Mission

Help every student know their next best step.

## 🌍 Vision

Become the most trusted AI companion for students.

## 💡 Core Principles

- Student First
- Trust over hype
- Verified opportunities
- Personalized guidance
- Continuous improvement

## 🚀 Current Status

Sprint 1: Building AI Prototype

## 📌 MVP Goal

A student should receive:

- 🎓 Relevant opportunities
- 💼 Career guidance
- 📚 Skill roadmap
- 📅 Weekly action plan

within 60 seconds.
